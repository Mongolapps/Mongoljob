# ServiGo Telegram Bot

MongolJob + үйлчилгээний захиалга + байнгын/цагийн ажлын нэгдсэн MVP.

## Боломжууд
- Хэрэглэгчийн анкет
- Үйлчилгээ хайх, цаг захиалах
- Байгууллага бүртгэх, админаар батлах
- Байгууллага үйлчилгээ нэмэх
- Байнгын болон цагийн ажлын зар
- Match хувь, хоёр талын зөвшөөрөл
- Premium/VIP ажлын зар
- `/stats` админ статистик

## Ажиллуулах
1. `bot.py`, `database.py`, `requirements.txt`-ийг нэг хавтаст байрлуулна.
2. `.env.example`-ийг `.env` болгон хуулж утгуудаа солино.
3. `pip install -r requirements.txt`
4. `python bot.py`

SQLite сан `servigo.db` нэрээр автоматаар үүснэ.
